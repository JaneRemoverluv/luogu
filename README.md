# luogu 错题本

洛谷错题收集与复习仓库。

## 使用方法

1. 每道错题在 `problems/` 下建一个文件夹：`P题号_题目标题/`
2. 复制 `TEMPLATE.md` 为该文件夹下的 `note.md` 并填写
3. `wrong.cpp` 放当时的错误代码，`sol.cpp` 放 AC 代码
4. 提交推送（或直接叫我提交）

## 复习规则

按 1 → 3 → 7 → 14 → 30 天间隔重做，不看笔记从零写，通过才进入下一间隔。30 天通过后状态改为「掌握」。
